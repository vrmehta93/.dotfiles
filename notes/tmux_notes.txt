
<c-b> - tmux default leader key

All tmux commands include prepending with leader key
Common (default) keybindings:
d - detach from current session
c - create new session
n/p - switch to next/previous window
% - split vertically
	overwrite with"|"
" - split horizontally
	overwrite with "-"
x - kill current pane
? - display list of all keybindings
